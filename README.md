# 🍺 Bar do Gordo — Landing Page

Landing page do **Bar do Gordo**, bar tradicional de Ivoti/RS, fundado em **1949** por Hugo Möbus.

Site institucional de página única, construído sem frameworks — apenas HTML, CSS e JavaScript puros.

## 📁 Versões

| Pasta | Descrição |
|---|---|
| `BardoGordo1.0/` | Primeira versão da landing page |
| `BardoGordo2.0-Completo/` | Versão atual, com conteúdo e seções ampliados |

Cada pasta é autocontida (`index.html`, `styles.css`, `script.js`).

## 🚀 Como rodar

Não há build nem dependências. Basta abrir o arquivo:

```bash
open BardoGordo2.0-Completo/index.html
```

Ou servir localmente, para evitar restrições de `file://`:

```bash
python3 -m http.server 8000
```

Depois acesse `http://localhost:8000/BardoGordo2.0-Completo/`.
